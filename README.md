# SOC-Automation-Lab

## Overview
This project is a cybersecurity lab focused on security monitoring, detection, and automated incident response using Wazuh, Python, Windows, and Linux, running on a more complex topology with 4 VMs.

## Objectives
- Build a virtualized SOC environment
- Centralize and analyze security events using Wazuh
- Develop automated incident response capabilities
- Create a Python API to trigger defensive actions
- Document the detection and response workflow
